A terminal user interface for the Slurm REST API. Monitor jobs, nodes and partitions, inspect job details and compose API requests from your shell — no SSH into the master node.

Quick Start

Build

go build -o srest .

Configure

Point it at your slurmrestd and authenticate with a JWT

export SLURM_URL=http://localhost:6820
export SLURM_JWT=$(scontrol token | cut -d= -f2)

Run

./srest

FAQ

Does srest need SSH access to the cluster?

No. srest talks to slurmrestd over HTTP using JWT authentication, so it only needs network access to the REST API endpoint — exactly what it is designed for.

Can I see the contents of job logs?

The Slurm REST API exposes the location of logs (standard_output/standard_error) but not their contents, since those are files on the cluster filesystem. srest shows the log paths; reading the actual files requires filesystem access, which is out of scope for the REST API.

Which Slurm API versions are supported?

srest auto-detects the data_parser version served by the cluster (v0.0.40 through v0.0.45) and version-gates request fields so it does not send parameters the version does not support.
